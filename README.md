# Sitemap Test Website

A small static website for testing sitemap fetching.

## Vercel deployment

Import this repository into Vercel. Choose **Other** as the framework preset and set **Output Directory** to `public`.

After deployment, replace `REPLACE-WITH-VERCEL-DOMAIN` in `public/sitemap.xml` and `public/robots.txt` with the exact assigned `.vercel.app` hostname, then commit the changes and redeploy.
